# ML Kit Removal Plan

## Overview
Remove ML Kit entirely from the app — all dependencies, features, and UI components.

## Files to Delete
- `app/src/main/kotlin/com/exapps/mangaworld/core/ml/MlKitPageTranslator.kt`
- `app/src/main/kotlin/com/exapps/mangaworld/core/ml/MlKitCoverTagger.kt`
- `app/src/main/kotlin/com/exapps/mangaworld/core/ml/MlKitSmartReplySuggester.kt`

## Files to Modify

### 1. `app/build.gradle.kts` — Remove ML Kit dependencies
Remove these lines:
```kotlin
implementation("com.google.mlkit:text-recognition:16.0.1")
implementation("com.google.mlkit:translate:17.0.3")
implementation("com.google.mlkit:smart-reply:17.0.4")
implementation("com.google.mlkit:image-labeling:17.0.9")
implementation("com.google.mlkit:language-id:17.0.6")
```

### 2. `FirebaseRemoteConfigManager.kt` — Remove ML flags
Remove:
- `_mlTranslationEnabled` / `mlTranslationEnabled` StateFlow
- `_mlSmartReplyEnabled` / `mlSmartReplyEnabled` StateFlow
- `_mlCoverTaggingEnabled` / `mlCoverTaggingEnabled` StateFlow
- `isMlTranslationEnabled()`, `isMlSmartReplyEnabled()`, `isMlCoverTaggingEnabled()` functions
- Related defaults in `setDefaultsAsync()`
- Related state in `applyState()`

### 3. `ReaderViewModel.kt` — Remove translation logic
- Remove `MlKitPageTranslator` injection
- Remove `PageTranslationUiState` data class
- Remove `translation` field from `ReaderUiState`
- Remove `translateCurrentPage()` method
- Remove `clearTranslationResult()` method
- Remove `mlTranslationEnabled` observation in `init{}`

### 4. `ReaderScreen.kt` — Remove translation UI
- Remove `ReaderTranslationSheet` composable
- Remove translation-related state variables
- Remove translation bottom sheet
- Remove translate button from settings sheet

### 5. `CommunityScreen.kt` — Remove smart reply
- Remove `MlKitSmartReplySuggester` injection
- Remove smart reply suggestion logic
- Remove smart reply UI components

### 6. `CommunityChatScreen.kt` — Remove smart reply
- Remove `MlKitSmartReplySuggester` injection
- Remove smart reply suggestion logic

### 7. `LocalStorageScreen.kt` — Remove cover tagging
- Remove `MlKitCoverTagger` injection
- Remove auto-tagging logic

### 8. `SettingsScreen.kt` — Remove ML Kit section
- Remove any ML Kit related settings (if added)

### 9. `ProGuard rules` — Remove ML Kit rules
- Remove: `-keep class com.google.mlkit.** { *; }` and `-dontwarn com.google.mlkit.**`

### 10. `Widgets` — Remove ML-dependent features
- Check if any widget uses ML Kit features (cover tagging, smart reply)
- Remove those dependencies

## Verification
- Build passes without ML Kit dependencies
- No references to `com.google.mlkit` remain in source code
- Translation button removed from reader
- Smart reply removed from community
- Cover tagging removed from local storage
