- kotatsu-parsers uses a separate module architecture — MangaWorld has parsers inline
- New sources should follow the existing `BaseScraperImpl` pattern
- The "More" screen should use a grid/list layout with icons and labels
- Sources screen should show real-time source status
- All new screens need Arabic labels and RTL support
