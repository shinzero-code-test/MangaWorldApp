# Kotatsu Feature Analysis — Missing Features in MangaWorld

## Executive Summary
After analyzing 1031 Kotlin files in kotatsu, here are the key missing features organized by priority.

---

## HIGH PRIORITY — Missing Features

### 1. Tap Grid Customization (Reader)
**Kotatsu:** `reader/ui/tapgrid/TapAction.kt` + `TapGridDispatcher.kt`
- Customizable tap zones with visual overlay
- 6 configurable actions: PAGE_NEXT, PAGE_PREV, CHAPTER_NEXT, CHAPTER_PREV, TOGGLE_UI, SHOW_MENU
- Each zone has a color indicator
- User can assign different actions to different screen areas

**MangaWorld:** Has basic tap actions but no visual customization or zone configuration.

### 2. Color Filter Configuration (Reader)
**Kotatsu:** `reader/ui/colorfilter/` package
- Dedicated activity for configuring color filters
- Custom filter presets
- Save/load filter configurations
- Preview before applying

**MangaWorld:** Has basic filters (grayscale, sepia, etc.) but no custom configuration UI.

### 3. Advanced Backup System
**Kotatsu:** `backups/` package with 10 backup sections:
- INDEX, HISTORY, CATEGORIES, FAVOURITES, SETTINGS, BOOKMARKS, SOURCES, SCROBBLING, STATS, SAVED_FILTERS
- ZIP-based with streaming
- Selective restore
- Progress tracking
- Periodic backup service

**MangaWorld:** Has basic JSON export/import. Missing: ZIP format, selective restore, periodic backups.

### 4. Suggestions Engine
**Kotatsu:** `suggestions/` package
- Persistent storage with relevance scores
- Source/genre filtering
- Top tags/sources for filtering
- Random list generation
- Background refresh

**MangaWorld:** Has basic `getSuggestedManga()` but no persistence, no scoring, no filtering.

### 5. Filter Presets
**Kotatsu:** `filter/` package with `PersistableFilter`, `SavedFiltersRepository`
- Save filter combinations per source
- Persistent filter state
- Filter history
- Complex filter combinations

**MangaWorld:** Has basic filters but no saved presets.

---

## MEDIUM PRIORITY — Missing Features

### 6. Alternatives / Cross-Source Search
**Kotatsu:** `alternatives/` package
- Parallel search across all sources
- Relevance scoring
- Source priority by locale/content type
- Flow-based results

**MangaWorld:** Has `otherSourceMatches` in detail screen but no dedicated alternatives search.

### 7. Bookmarks System
**Kotatsu:** `bookmarks/` package
- Named bookmarks within chapters
- Page-specific bookmarks with notes
- Bookmark list management
- Bookmark categories

**MangaWorld:** Has page annotations but no dedicated bookmark management.

### 8. History Management
**Kotatsu:** `history/` package
- Detailed reading history
- History cleanup policies
- History statistics
- Recently viewed

**MangaWorld:** Has basic history but less detailed tracking.

### 9. Content Picker
**Kotatsu:** `picker/` package
- Unified manga picker across sources
- Search within picker
- Recent picks

**MangaWorld:** No unified picker component.

### 10. Image Viewer
**Kotatsu:** `image/` package
- Full-screen image viewer
- Zoom, pan, double-tap zoom
- Save to gallery

**MangaWorld:** Reader handles images but no dedicated full-screen viewer.

### 11. Reader State Persistence
**Kotatsu:** `reader/data/` package
- Save/restore reader state
- Scroll position persistence
- Orientation handling

**MangaWorld:** Has basic state but less sophisticated.

## LOW PRIORITY — Nice to Have

- Proxy authentication

### 13. Discord Integration
**Kotatsu:** `scrobbling/discord/`
- Discord webhook notifications
- Reading activity sharing

### 14. Advanced Reader Gestures

- Volume button navigation

### 15. Widget Shelf
**Kotatsu:** `widget/shelf/`
